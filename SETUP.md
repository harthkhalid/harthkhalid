# Publish this profile README

1. On GitHub, create a **new public repository** named **exactly** `harthkhalid` (same as your username).  
   Leave it empty (no README) or delete the default README after.

2. Copy **everything** from this folder into that repository root:
   - `README.md`
   - `.github/workflows/snake.yml`

3. Commit and push to `main`.

4. In the repo: **Settings → Actions → General → Workflow permissions** → allow **Read and write** (so the snake job can push to the `output` branch).

5. Open **Actions** → run **Generate snake animation** manually once. After it completes, the snake images will exist at `output/` and your README will show them.

6. Edit `README.md`: replace placeholder links (LinkedIn, email), featured projects, and skill icons to match you.
